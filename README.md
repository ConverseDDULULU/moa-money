# 모아 돈 관리 앱

설치 없이 브라우저에서 바로 쓰는 돈 관리 앱 두 가지예요.

| 앱 | 누구에게 | 주요 기능 |
|---|---|---|
| **모아 가계부** (`household/`) | 개인 | 통장·예적금·주식·대출을 합친 순자산, 가계부, 월 고정비, 월급날까지 남는 돈, 예적금 세후 이자, 해외주식 양도세 계산, 중복 결제·수수료·오른 구독료 알림 |
| **돈흐름 장부** (`company/`) | 작은 회사 | 통장·법인카드·세금계산서를 합친 월 결산, 미수금 자동 찾기, 거래 분류 규칙, 자금일보, 위하고용 전표 엑셀 |

## 쓰는 법

- **바로 쓰기**: 이 저장소의 GitHub Pages 주소(`https://<아이디>.github.io/<저장소>/`)를 열고 앱을 고르면 돼요.
- **파일로 받기**: [Releases](../../releases/latest)에서 `moa-household.html` 또는 `money-ledger.html`을 받아 더블클릭하면 브라우저에서 열려요. 글꼴과 엑셀 기능 때문에 인터넷 연결은 필요해요.

## 데이터는 어디에 저장되나요?

서버가 없어요. 입력한 내용은 **쓰는 사람의 브라우저(localStorage)에만** 저장돼요. 같은 링크를 쓰는 다른 사람에게는 보이지 않아요. 브라우저 기록을 지우면 사라질 수 있으니, 앱 안의 **백업 파일 받기**로 가끔 백업해 두세요.

## 세금 계산 기준 (2026년, 참고용)

- 해외주식 양도소득세: 1년 손익을 합친 뒤 기본공제 250만원을 빼고 22%(양도세 20% + 지방소득세 2%), 다음 해 5월 신고
- 국내 상장주식: 대주주(한 종목 50억원 이상 등)가 아니면 양도세 없음, 증권거래세 0.20%
- 국내 상장 해외·채권 ETF: 매매차익에 배당소득세 15.4%(추정)
- 예금·적금 이자: 일반과세 15.4%, 세금우대 9.5%, 조합 예탁금 1.4%, 비과세 선택

세법은 바뀔 수 있어요. 실제 신고는 홈택스나 세무사에게 확인하세요. 이 앱은 투자·세무 조언이 아니에요.
